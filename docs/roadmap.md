The critical path now starts with **existing linkage + early precision + selection/review readiness → bounded go/adapt/stop checkpoint → justified further coverage/construction → final design-specific precision → preregistration → main research → manuscript/reproduction → Pages**. The [55-pair checkpoint](feasibility/nrw-close-election-evidence-review.md) supports six mixed pairs; only three provisionally intersect the candidate window. The full 214-pair ledger is required for a final positive NRW go decision; an early adapt/stop can precede that extensive work. Prediction labels do not define eligibility.

Planning allowances are approximately **17–33 focused working days to the full feasibility decision**, including an early checkpoint after about **3–6 days**. A successful go decision is followed by approximately **10–18 days for the main specification, analysis and manuscript**, then **2–4 days for Pages**. A conditional expansion starts with a separate **3–5 day audit**, not a promise to finish another state dataset within that period. These are effort estimates; provider delays, missing evidence and scope changes can alter the calendar. No completion date is promised.
