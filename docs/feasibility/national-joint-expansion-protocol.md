## Complete source frame and metadata screen

Retain all 654 structurally reconciled GERDA municipal decisive election events from 2018–2025 within 10 pp, including the 396 events with incomplete candidate names. These are 629 municipalities, not 654 independent geographic clusters. The previously verified 114-election acquisition frame remains frozen. Screen all retained events, regardless of presentation predictions or existing procurement outcomes, against the fifteen already verified monthly national CSV archives: January–December 2025 and January–March 2026. Use the established exact sole municipal buyer-role name rules and terminal `, Stadt` alias normalization; retain conflicting names as unresolved. Identical duplicate notice/version records are counted once, conflicting duplicates halt execution.

For events through 2024, metadata discovery uses calendar 2025. For 2025 events, use Q1 2026. This broad availability screen does **not** assert that an elected mayor remained in office throughout the window. Election age, turnover and left-truncated post-election outcomes are explicit; office/exposure verification is required before any treatment-outcome eligibility decision. Missing candidates are retained. Repeated-municipality events receive separate event keys and a shared cluster key; the same notice may generate multiple event links and must never be counted as multiple independent procurements.

This late-term window avoids selecting call dates after the regular term turnover; it is not a first-year window or comparable to NRW 2025 without a design justification.

Query standard competition/result context for all observed call-first GUIDs in this new cohort through 30 September 2026, without a lower publication-date bound. Use complete capped TED API snapshots and at most 8 API pages. Reuse all 259 pinned daily original-export snapshots; **no new daily XML archives** in this batch. Counts after actual mayoral turnover require an exposure decision, even if the original call predates turnover. Incomplete revisions or missing originals remain unresolved, not zeros. The old 114-election audit remains unchanged; combine inventories only as acquisition bookkeeping and explicitly report distinct municipalities/repeated clusters.

## Candidate and readiness checks

Existing historical first-coder evidence may be reused only if original sources and election identities are pinned and matched. New presentation claims require dated person-specific primary evidence; inferred labels remain discovery leads. No primary effect estimation, no automatic pooling and no declaration of main-study readiness. Report verified joint cases by cohort and narrow-band stratum; assess precision at election/municipality level, not lot level. Independent second coding, exact office entry/turnover, complete result coverage, outcome definition, RDD design diagnostics and a justified precision decision remain launch gates.
