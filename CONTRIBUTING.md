# Working conventions

Use English for project prose, comments, identifiers, commit messages, and new filenames. Preserve titles and wording in original-language quotations and source documents.

Separate verified evidence, assumptions, planned analyses, and empirical findings. Cite primary sources and record access dates. Do not describe a source as verified or a milestone as complete without supporting work.

Keep acquisition, cleaning, linkage, estimation, and presentation logically separate. Document meaningful changes to sample construction and analysis choices in the decision log. Pin dependencies once an implementation stack is selected.

Before committing, inspect the diff and confirm that raw data, credentials, confidential records, and generated artifacts have not been included. Run checks appropriate to the code changed and record relevant validation.

GitHub Pages publication is deferred until the research is complete. Do not add automatic deployment on pushes during the research phase.
